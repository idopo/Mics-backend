  <behavior>
    - `fake_pigpio` models **stock upstream pigpio**, not the Autopilot-patched client. It exposes:
      `pi(host='localhost', port=8888, show_errors=True)` with `.connected`, `.callback(user_gpio,
      edge, func)` returning an object with `.cancel()` / `.tally()` / `.reset_tally()`,
      `.get_current_tick()`, `.read(gpio)`, `.write(gpio, level)`,
      `.set_watchdog(user_gpio, wdog_timeout)`, `.stop()`; the module constants
      `RISING_EDGE FALLING_EDGE EITHER_EDGE`, `MSG_SIZ = 12`; the `pulse(gpio_on, gpio_off, delay)`
      record type; and `class error(Exception)`.
    - **Every call is appended to a `.calls` list as `(name, args, kwargs)`**, so a test can assert
      the exact sequence a production call produced.
    - **The 32-bit tick is structural, not asserted.** `fire_edge` packs the notification with
      `struct.pack('HHII', seq, flags, tick, level)` and dispatches from
      `struct.unpack('HHII', msg)`. A tick of `2**32` therefore raises `struct.error` on its own,
      with no width check written by hand. `MSG_SIZ` equals `struct.calcsize('HHII')` equals 12.
    - **Edge injection — the single most load-bearing feature of this fake.** Every clock assertion
      in plans C1/C2 is of the form "inject tick T, read a known 64-bit monotonic value back out".
      A fake that records a registration but cannot fire it makes all of them unwritable. So:
      - `pi.callback(user_gpio, edge, func)` appends to ONE ordered registration list — mirroring
        the real client's single `_callback_thread.callbacks` list — recording `user_gpio`, the
        `edge` mask and `func`. `.cancel()` removes **that one entry**, not the whole pin.
      - `fake_pigpio.fire_edge(gpio, level, tick=None)` invokes **every live registration whose
        `user_gpio` matches and whose edge mask admits `level`**, **sequentially, in registration
        order, from the single simulated notify thread** — because that ordering is exactly what
        makes `if tick < last_tick: wraps += 1` valid, and a fake that dispatched concurrently or
        out of order would make a broken wrap counter pass. Each is invoked with pigpio's **3
        positional** arguments `(gpio, level, tick)`. `tick` defaults to the current fake tick.
      - `fire_edge` returns the number of registrations it invoked, so a test can assert that one
        edge reached **both** dispatch routes (`Digital_Out.is_trigger = True` with `record=True`
        makes two registrations on one pin the normal case, not the exception).
      - `fire_edge` on a pin with no live registration returns 0 and does not raise.
      - `level == 2` (watchdog timeout) is injectable like any other level. The fake does not
        interpret levels; that is the clock module's job.
      - `fire_edge` records itself in `.calls`, so a test can interleave commanded output and
        injected input on one timeline.
    - **Wrap injection.** `fake_pigpio.set_tick(t)` sets the value `get_current_tick()` returns;
      `advance_tick(us)` advances it **modulo 2**32**; `simulate_wrap(pre_us=1000)` positions the
      tick at `2**32 - pre_us` so the next `advance_tick` past `pre_us` restarts it near zero.
      After a wrap, a subsequent `fire_edge()` therefore carries a tick **numerically smaller** than
      the one before it, and `get_current_tick()` agrees. This is the 71.6-minute defect reproduced
      in microseconds, and it is what the whole clock module exists to survive.
    - **Registration counts are assertable:** `registration_count()` returns the number of live
      registrations, `registration_count(gpio)` the number for one pin.
    - **Exceptions raised inside a fired callback propagate out of `fire_edge`** rather than being
      swallowed. The real `_callback_thread.run()` does not catch either — an exception there kills
      the notify thread and every event after it. A fake that ate it would make the clock module's
      containment tests pass vacuously.
    - Any method can be armed to raise `fake_pigpio.error`, so error containment is testable.
    - A `fake_pigpio` pytest fixture installs the fake at `sys.modules['pigpio']` BEFORE the module
      under test is imported, and removes it on teardown.
  </behavior>
