# Phase 2, Plan 2: Notebook Section 1 — Events (standalone, cached)

**Phase goal:** The notebook gains a documented, cacheable Events section that turns each resolved session into a displayed events DataFrame using only Elasticsearch — the always-available base layer.

**Context:**
Section 1 is the first real data section and the foundation everything else decorates. It must run with zero ephys dependencies so behavior-only sessions are fully usable here. Caching mirrors the legacy pickle habit but keyed cleanly per session.

**Depends on:** `ElasticClient.fetch_events` (02-01), `cache.cached_pickle` (01-01), notebook skeleton (01-02).

## 1. Extend `notebooks/build_notebook.py` — append Section 1 cells

**md — "## Section 1 · Behavioral Events (Elasticsearch)"**
- This layer always works (no ephys needed).
- Column reference: `event_type`, `hardware_id`, `level`, `raw_time`, `relative_time`, `run_id`/`subjects` (null for legacy data), `event_data` (raw dict).
- Cached per session key under `cache/<key>/events.pkl`; delete the cache or pass `force=True` to refetch.

**code — build events per session (cached)**
```python
from mics.elastic import ElasticClient
from mics.cache import cached_pickle

events = {}
for s in sessions:
    events[s.key] = cached_pickle(
        s.key, "events",
        lambda s=s: ElasticClient(s.es_host).fetch_events(s),
    )
    print(f"{s.key}: {len(events[s.key])} events")
```

**code — display one session's events**
```python
key = sessions[0].key
df = events[key]
display(df.head(20))
df.event_type.value_counts()
```
