    **Hard constraints, in priority order:**
    1. **ZERO `autopilot` imports at module scope** — same rule and same reason as plan 18-05.
       Plan 18-02's hygiene test enforces it. Callbacks (`on_drop`, `on_alive_change`) are how

    2. Stdlib only (`queue`, `threading`, `time`), **Python 3.7-compatible syntax** — the dev

    3. **No retry, ever.** A failed `send_fn` is logged via the callback and dropped. A retried
       marker arrives at the WRONG timestamp; for alignment a late marker is strictly worse than
       a missing one, because it silently corrupts co-registration instead of leaving a visible
       gap. Put that sentence in the docstring so nobody "fixes" it later.
    4. **Overflow drops the NEWEST and RECORDS the loss.** `dropped` increments and `on_drop`
       fires with the rejected item. Silent truncation would make the event log look complete
       when it isn't. Dropping the oldest was explicitly rejected — the oldest entries are
       already sequenced and nearest delivery, so evicting them tears a hole mid-sequence.
    5. **`on_alive_change` is edge-triggered.** It fires once when `consecutive_failures` first
       reaches `fail_threshold`, and once again on the first success after a failing streak.
       Level-triggered firing would spam the event log and make the flip useless as a signal.

    `enqueue()` must never block and never raise — it returns `False` when it drops. `stop()`
    must be idempotent and must join with a bounded timeout so a wedged `send_fn` cannot hang
    `Task.end()`.

    Default `maxsize=64` and `fail_threshold=3` (Claude's discretion per 18-CONTEXT). One OS
    thread per instance — this rig will have at most a handful of external modules per pilot,
    so thread count is a non-issue and per-device FIFO ordering is trivially provable.

    False, is retried every `retry_interval_s` until `timeout_s` elapses on the injected
    `clock`. This converts a hard failure into a recoverable one: the researcher starts the

    field addition fails loudly at the source rather than at some subclass.
