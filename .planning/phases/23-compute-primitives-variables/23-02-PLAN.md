<objective>
Add backend guardrails and storage for compute/variables: extend `_validate_task_definition`
to reject (422) malformed variable usage; extend the `fda_utils` ref scanner to see
compute outputs; and store the shared compute primitive library via the existing Phase-9
hardware-lib DB infra (no new table), with AST extraction surfacing each primitive's
signature so the GUI (23-03) can build a primitive picker.

Purpose: Catch bad task definitions before they reach the Pi, and give the GUI a single
source of truth for available compute primitives + their args.
Output: `fda_utils.py` scanner edits; a NEW `api/fda_validation.py` module holding the variable
validation logic; a thin import+call in `toolkits.py`; and a `hardware_libs.py` AST-extractor
extension for module-level functions.
</objective>
