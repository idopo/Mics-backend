<objective>
Make the sourceless detector path actually work on the Pi, and make the tracker it writes
pilot-agnostic.

Purpose:
- **TRIGA-12** is the load-bearing change. `check_for_detectors` filters with
  `isinstance(v, Touch_Detector)` against the class imported at `mics_task.py:17`, while
  `_resolve_hardware_classes` `exec`s the registry's copy of `i2c.py` into a fresh namespace —
  a *different class object*. Zero matches → no `add_Tracker` → no `LICKER0..3` → a `view`
  action writes a key that does not exist: no exception, no data. One predicate stands between
  the current state and working lick detection.
- **TRIGA-18** stops the task definition from becoming pilot-specific. `LICKER` is
  `device_name` from `pilot_hardware_config`; baking `"LICKER{pin_number}"` in at save time is
  a silent no-op on a pilot whose MPR121 is named `TONGUE`. The `view` action gains
  `source_ref` and `key_template` gains a runtime-resolved `{device_name}` token.
- **TRIGA-19** locks the value source: both `pin_number` *and* `level` come from action[0]'s
  captured `output`. `execute_trigger`'s `level` is the IRQ assert/deassert edge, not electrode
  state — run 475's tidy alternating 0/1 was that handshake. With four electrodes,
  `{"trigger":"level"}` would write interrupt polarity into whichever `LICKER` changed: wrong
  data that looks correct in ES.

Output: a `mics_task` that creates detector trackers for registry-declared detectors, a `view`
action that resolves its target through the source device's own name, a CLI validator that
agrees, and a unit suite that pins the canonical payload's value source.
</objective>

```python
def _has_detector_capability(obj) -> bool:
    """A detector exposes N named channels and a bulk read().

    Capability, NOT isinstance: a detector declared through the hardware-module registry has
    its class exec'd from source_code by _resolve_hardware_classes into a fresh namespace, so
    it is a different class object from autopilot.hardware.i2c.Touch_Detector even though it
    is the same code. Identity matching yields zero detectors, no LICKER trackers, and a view
    action that writes a key which does not exist: no exception, no data.

    n = getattr(obj, "num_detectors", None)
    name = getattr(obj, "device_name", None)
    return (
        isinstance(n, int) and not isinstance(n, bool) and n > 0
        and isinstance(name, str) and name != ""
        and callable(getattr(obj, "read", None))
    )
```
