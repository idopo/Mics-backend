```python
def run_run_artifacts_migration(eng):
    """Phase 26: device-neutral run_artifacts table — idempotent."""
    with eng.begin() as conn:
        conn.execute(text("CREATE TABLE IF NOT EXISTS run_artifacts (...)"))
        conn.execute(text("CREATE INDEX IF NOT EXISTS ... ON run_artifacts (target_path)"))
```

Table shape (device-neutral by design — a device-specific column here is a defect):
```
id                SERIAL PRIMARY KEY
run_id            INTEGER NOT NULL REFERENCES session_runs(id)
device_name       VARCHAR NOT NULL          -- the pilot_hardware_config module name
device_class      VARCHAR                   -- class_name, so the stop registry can dispatch
host              VARCHAR                   -- which machine wrote it
target_path       TEXT NOT NULL             -- what MICS asked for; the collision key
resolved_path     TEXT                      -- the TRUE final path, READ BACK; NULL until reported
project_name      VARCHAR                   -- snapshot, closes the rename risk
experiment_name   VARCHAR                   -- snapshot
subject_name      VARCHAR                   -- snapshot
started_at        TIMESTAMP
ended_at          TIMESTAMP
coverage_complete BOOLEAN NOT NULL DEFAULT FALSE
ambiguities       JSONB NOT NULL DEFAULT '[]'::jsonb
device_fields     JSONB NOT NULL DEFAULT '{}'::jsonb   -- OE: experiment_number/recording_number.
                                                       -- DLC: camera identity. Never a column.
created_at        TIMESTAMP DEFAULT NOW()
UNIQUE (run_id, device_name)
```

  <name>Task 2: api/artifacts.py — the device-neutral record store</name>
  <files>api/artifacts.py</files>
  <behavior>
    - create → report → close round-trips every field including the device_fields blob
    - A second create for the same (run_id, device_name) updates rather than duplicating
    - find_path_collision reports another run's row and never reports the caller's own run
    - Closing an artifact that was never reported marks coverage_complete False
  </behavior>
  <action>
    Create the module. Its docstring must state that it is **device-agnostic**, name the one
    accepted residual gap verbatim — *a folder created by hand outside MICS is invisible to this
    check, because the collision check is a MICS-side uniqueness check against this table, not a
    filesystem probe* — and say that device-specific values belong in `device_fields`, never in a
    new column. Plan 26-01's `test_collision_gap_is_documented` asserts on this docstring.

    Implement the six functions with `sqlalchemy.text` and bound parameters. Notes:
    - `create_artifact_target` is an UPSERT on `(run_id, device_name)` (`ON CONFLICT ... DO UPDATE`).
      A re-planned run must not duplicate a row; the unique constraint is the arbitration primitive.
      It stores `target_path` plus the snapshot fields taken from `tokens` and the `ambiguities` list.
    - `report_artifact_resolved` writes the **read-back** path and `started_at`, and merges
      `device_fields` rather than replacing the whole blob.
    - `close_artifact` writes `ended_at` and `coverage_complete`. **`coverage_complete` is True only
      when the device recorded for the run's full duration** — an unclean stop (plan 26-08) closes
      with False, which is what lets analysis filter partial sessions with a query instead of by eye.

      **Coverage is resolved PER ROW here, not taken from the caller.** A row with
      `resolved_path IS NULL` (equivalently `started_at IS NULL`) means the device never actually
      began recording, so it closes `coverage_complete = False` **regardless of what the caller
      passed**. This store owns the semantics; callers must not be able to assert coverage the data
      contradicts.

      Why this matters: `26-11`'s clean-stop path calls `close_run_artifacts(coverage_complete=True)`
      for the whole run, and several routine paths reach a *clean* stop with a device that recorded
      nothing — `required: false` (a Phase 18 key) against a busy or unreachable box, an
      `on_run_start` that failed for the entire wait window, or a per-run opt-out. Trusting the
      caller would stamp `coverage_complete = TRUE` on exactly the rows the flag exists to catch,
      and `26-12` would render them as complete. That inverts `26-CONTEXT.md`'s locked decision:
      *mark the recording incomplete when OE was not recording for the run's full duration, so
      analysis can filter partial sessions with a query instead of discovering them by eye.*
    - `find_path_collision(db, target_path, run_id=None)` returns the first row whose `target_path`
      matches and whose `run_id` differs, as a dict naming the other run, its device and its
      subject. Returns `None` when the only match is the caller's own run — a run never collides
      with itself, which is what makes preflight re-runnable.
    - Every function takes an explicit `db` SQLAlchemy session; the module opens none of its own, so
      callers control the transaction.

    Keep under 300 lines.
  </action>
