**Byte-exact msgpack wire codec (`mics_link.wire`) matching the Pi's `external_hardware_wire.encode()` for SIG/EVT/HB/ACK, packaged as a standalone `pyzmq>=22`/`msgpack>=1.0` installable with a frozen golden-frame corpus locking parity behind a test.**

## Accomplishments

- `sdk/` is a self-contained, installable package (`pip install --target` proven) declaring
  exactly two runtime dependencies, both floored per the SDK-14 amendment.
- SDK-02 is enforced by a test, not review: `mics_link.wire`'s raw bytes are byte-identical to
  `~/mics_core`'s `external_hardware_wire.encode()` output for SIG (float/int/bool/str value
  variety), EVT, HB, ACK; `decode_cmd` correctly extracts CMD fields; `decode_envelope` never
  raises on garbage.
- SDK-11's hygiene half holds and is now guarded package-wide (not just wire.py): no
  module-scope zmq-family import, no import-time side effects, no POSIX-only names anywhere
  in `mics_link`.
- The canonical-reference-path decision is locked in exactly one place
  (`sdk/tests/pi_reference.py`), with the secondary `~/pi-mirror` tree wired as a
  skip-if-absent drift check — both trees confirmed byte-identical at execution time.
- Added `mics_link.selfcheck` (not in any plan's files_modified, but explicitly mandated by
  this plan's own SDK-14 amendment text) — detects a globally `msgpack_numpy`-patched process
  before it silently corrupts every frame the SDK emits.

**2. [Rule 3 - Blocking issue] Dev host Python is PEP-668 externally-managed**
- **Found during:** Task 2 (running `cd sdk && python3 -m pytest -q tests/test_wire_parity.py`)
- **Issue:** `pip install -e ./sdk` (the natural way to make `mics_link` importable for a

  repo's dev host refuses non-apt Python package installs without `--break-system-packages`,
  which risks the host's system Python.
- **Fix:** Added `sdk/tests/conftest.py`, a `sys.path` shim inserting `src/` — the standard
  idiom for testing a src-layout package without installing it. Does not touch the host
  Python at all. Task 3's isolated `--target` install is the actual packaging proof; this
  shim is test-only infrastructure.
- **Files modified:** `sdk/tests/conftest.py` (new)
