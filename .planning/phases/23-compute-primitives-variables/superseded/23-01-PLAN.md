```python
def init_flags(self):
    for flag_name, flag_info in self.FLAGS.items():
        tracker_class = flag_info["type"]
        initial_value = flag_info.get("initial_value", None)
        name = flag_info.get("name", flag_name)
        tracker = tracker_class(info_type=name, initial_value=initial_value,
                                event_dispatcher=self.event_dispatcher)
        self.flags[flag_name] = tracker
        self.view.view[flag_name] = tracker
```

Generic untyped base (utils/Tracker.py) — confirmed the right base for variables:
```python
class Tracker(Mics_Tracker):
    def __init__(self, info_type, initial_value, event_dispatcher=None): ...

    def get_state(self): return self.value
    # .value attribute holds current value
```

  <files>~/pi-mirror/autopilot/autopilot/tasks/compute_primitives.py</files>
  <action>
    Create a new module of PURE functions using ONLY Python stdlib `random`/`math` +
    builtins (no third-party imports — portability rule, decision #3). Implement the
    curated primitives (CMP-04):

    Random / copy (existing):
      - `random_choice(seq)` → returns `random.choice(list(seq))`
      - `random_int(min_val, max_val)` → returns `random.randint(min_val, max_val)` (inclusive)
      - `random_float(min_val, max_val)` → returns `random.uniform(min_val, max_val)`
      - `random_bool(p)` → returns `random.random() < p` (p = probability of True)
      - `assign(value)` → returns `value` unchanged (copy a literal/param/flag/variable into output)

    Numeric / util (NEW — simple value-production for derived numbers + counters):
      - `add(a, b)` → `a + b`
      - `subtract(a, b)` → `a - b`
      - `multiply(a, b)` → `a * b`
      - `divide(a, b)` → `a / b`; raise `ValueError` if `b == 0`
      - `modulo(a, b)` → `a % b`; raise `ValueError` if `b == 0` (enables "every Nth trial" patterns)
      - `minimum(a, b)` → `min(a, b)`
      - `maximum(a, b)` → `max(a, b)`
      - `clamp(value, lo, hi)` → `max(lo, min(value, hi))`; raise `ValueError` if `lo > hi`

    Do NOT add comparison/boolean-logic ops (gt/lt/and/or/not) — branching lives in FDA
    transitions and Phase 15 compound (DNF) conditions already cover boolean composition;
    duplicating it here would be a redundant second path. Numeric value-production only.

    The `add`/`subtract`/`clamp` ops over a variable read back as an arg (e.g.
    `add(<var>, 1) → <var>`) are the supported counter/tally pattern — one reused variable
    slot instead of a growing flag count. See Task 3 for the variable-as-arg resolution path.

    Expose a `PRIMITIVES: dict[str, callable]` registry mapping op-name → function so
    `_build_action_callable` can dispatch by `action["op"]`. Each function takes only the
    resolved arg values (the caller resolves args via `_resolve_arg`). Add a one-line
    module docstring noting stdlib-only constraint. Keep file under 150 lines.
    Each primitive must raise a descriptive `ValueError`/`TypeError` on bad arg shape rather
    than failing cryptically (e.g. random_choice on empty seq, divide/modulo by zero).
  </action>
