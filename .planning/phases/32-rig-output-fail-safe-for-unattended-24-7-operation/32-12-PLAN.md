<interfaces>
<!-- The two payloads the session UI actually reads, and what they leave out. -->

**`POST /sessions/pilots/{pilot_id}/latest-runs`** (`api/main.py:1463-1500`) is the SessionCard's
data source, called by `web_ui/react-src/src/api/sessions.ts` through the web_ui proxy path
`/api/sessions/pilots/{pilot}/latest-runs`. It returns per session id:
`{"run": {id, session_id, pilot_id, status, mode, started_at, ended_at}, "progress": {current_step, current_trial}}`.
It reads `run.error_type`, `run.error_message` and `run.auto_resume_count` from the ORM object it
already has in hand — it just does not put them in the dict.

**`SessionRunRead`** (`api/models.py`) has `id, session_id, pilot_id, subject_key, status,
started_at, ended_at, mode, overrides` — no error fields. It is the `response_model` for
`POST /session-runs` and `GET /sessions/{id}/active-run`.

**`GET /session-runs/{run_id}/with-progress`** (`api/main.py:1986`) returns a `run` sub-dict that
also omits the error fields; the orchestrator uses it, and plan 11's policy needs `auto_resume_count`
from it.

**`SessionRunStatus`** values are lowercase strings on the wire: `running`, `stopped`, `completed`,
`error`, `pending`.

**`error_type` values after plans 10 and 11:** `TaskError`, `TaskTeardownError`, `PilotRestarted`,
`WatchdogTimeout`, `OrchGatewayError`. Plan 11 appends the policy's decline reason to
`error_message` when it refuses to auto-resume, so `error_message` can carry both the crash reason
and the no-resume reason.

**Frontend conventions** (`CLAUDE.md`): pure logic in
`web_ui/react-src/src/components/<name>.mts` with its test at
`web_ui/react-src/tests/<name>.test.mts`, run by `npm run test:unit`. CSS lives in
`web_ui/static/style.css` (plan 07 corrected `CLAUDE.md`'s wrong path). Existing status classes:
`.status-stopped` and `.status-error` at lines 1242-1243, and `.run-status-error` at 2971. Reuse
them; do not invent new colour literals.

**Escaping:** `error_message` originates on the Pi and passes through the orchestrator. Render it as
React text only; `dangerouslySetInnerHTML` must not appear.
