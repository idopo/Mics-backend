# Phase 11, Plan 6: Hardware Library Selection During Toolkit Creation

**Phase goal:** When creating a backend-authored toolkit the user can pick which hardware libs to
link and choose a version for each (defaulting to latest stable). Links are stored immediately on
creation so TaskEditor hw lib chips appear without a separate post-creation step.

**Scope:** DB column + migration + router changes (backend) and 6-step creation modal (frontend).
No changes to the hw lib unlink endpoint or the task definition pin flow.

#### 3c. Check/uncheck handler

```typescript
const toggleLib = async (lib: HardwareLib) => {
  if (lib.id in selectedLibVersions) {
    // uncheck
    setSelectedLibVersions(prev => { const n = { ...prev }; delete n[lib.id]; return n })
  } else {
    // check — load versions lazily if not cached
    if (!libVersionCache[lib.id]) {
      const versions = await listVersions(lib.id)
      setLibVersionCache(prev => ({ ...prev, [lib.id]: versions }))
    }
    const defaultVersion = lib.stable_version_id ?? lib.active_version_id ?? null
    setSelectedLibVersions(prev => ({ ...prev, [lib.id]: defaultVersion }))
  }
}
```

In `api/hardware_libs.ts` add:

```typescript
export async function linkLib(toolkitId: number, libId: number, versionId: number | null): Promise<void> {
  return apiFetch(`/api/toolkits/${toolkitId}/hardware-libs`, {
    method: 'POST',
    body: JSON.stringify({ hardware_lib_id: libId, version_id: versionId }),
  })
}
```

Update `createMutation`:

```typescript
const createMutation = useMutation({
  mutationFn: (payload: BackendToolkitCreatePayload) => createBackendToolkit(payload),
  onSuccess: async (toolkit) => {
    const entries = Object.entries(selectedLibVersions)
    if (entries.length > 0) {
      await Promise.all(
        entries.map(([libId, versionId]) =>
          linkLib(toolkit.id, Number(libId), versionId)
        )
      )
    }
    onCreated()
  },
  onError: (e: Error) => setError(e.message),
})
```

`createBackendToolkit` must return the created toolkit object (with `id`). Confirm `api/toolkits.ts`
returns the full toolkit response; if it currently discards the return value, ensure it passes
through so `onSuccess` receives it.
