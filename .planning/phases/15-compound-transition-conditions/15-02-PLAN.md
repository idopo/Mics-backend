# Phase 15, Plan 2: Compound Conditions — ConditionGroupsEditor UI

**Requirements:** COND-02
**Phase goal:** Replace the single-condition `ConditionBuilder` in the transition edge panel with
a Kibana-style compound condition editor that lets users build OR-of-AND-group expressions.

**Scope:** New React component + TaskEditor wiring. No API or Pi changes (those are in Plan 1).

**Gate:** Requires Plan 1 (condition_groups types + updateTransitionGroups exist).

---

## Design reference

Kibana's `FiltersBuilder` (from `@kbn/unified-search-plugin`, v8.15.3 — code in the running Docker
container at `/usr/share/kibana/node_modules/@kbn/unified-search-plugin/public/filters_builder/`)
uses:
- `BooleanRelation.AND | OR` enum
- Recursive `CombinedFilter` tree (`{meta: {type:'combined', relation, params: Filter[]}}`)
- `FiltersBuilderReducer` with `addFilter / removeFilter / updateFilter / moveFilter` actions
- `FilterGroup` → `FilterItem` recursion, `Delimiter` components between items
- `addFilter` utility: wraps target in `buildCombinedFilter(relation, [target, new])` when
  parent's relation differs from the requested one

For MICS we use **flat DNF** (OR of AND-groups, max 2 levels). This covers all practical
behavioral experiment conditions without the complexity of an infinite-depth recursive UI.

## Step 1: Extract ConditionRow from ConditionBuilder

**File:** `web_ui/react-src/src/components/ConditionBuilder.tsx`

`ConditionBuilder` currently renders the full left/op/right row. Extract its body into a
`ConditionRow` named export so `ConditionGroupsEditor` can reuse it per-row.

Move the current JSX body of `ConditionBuilder` into `ConditionRow`, add an optional `onDelete`
prop that shows a `×` button:

  onDelete?: () => void
}

export function ConditionRow({
  condition, toolkit, hwModuleNames, onChange, onDelete
}: ConditionRowProps) {
  // (existing ConditionBuilder JSX body goes here)
  return (
    <div style={{ display: 'flex', gap: 6, alignItems: 'center' }}>
      {/* left-type selector + left-value input */}
      {/* op select */}
      {/* right-type selector + right-value input */}
      {onDelete && (
        <button
          onClick={onDelete}
          style={{ marginLeft: 4, fontSize: 11, color: 'var(--text-muted)',

## Step 2: Create ConditionGroupsEditor component

**File:** `web_ui/react-src/src/components/ConditionGroupsEditor.tsx` (new file)

Pure controlled component. No internal state — all mutations go through `onChange`.

```typescript
import React from 'react'
import { ConditionGroup, FdaCondition, ToolkitRead } from '../types'
import { ConditionRow } from './ConditionBuilder'

const EMPTY_CONDITION: FdaCondition = { left: { view: '' }, op: '==', right: 0 }

interface Props {
  groups: ConditionGroup[]
  toolkit: ToolkitRead | null
  hwModuleNames?: string[]
  onChange: (groups: ConditionGroup[]) => void
}

export function ConditionGroupsEditor({ groups, toolkit, hwModuleNames, onChange }: Props) {

  const updateCondition = (gi: number, ci: number, updated: FdaCondition) =>
    onChange(groups.map((g, i) =>
      i !== gi ? g : { conditions: g.conditions.map((c, j) => j === ci ? updated : c) }
    ))

  const deleteCondition = (gi: number, ci: number) => {
    const newConds = groups[gi].conditions.filter((_, j) => j !== ci)
    if (newConds.length === 0) {
      onChange(groups.filter((_, i) => i !== gi))       // remove empty group
    } else {
      onChange(groups.map((g, i) => i !== gi ? g : { conditions: newConds }))
    }
  }

  const addAndCondition = (gi: number) =>
    onChange(groups.map((g, i) =>
      i !== gi ? g : { conditions: [...g.conditions, { ...EMPTY_CONDITION }] }
    ))

  const addOrGroup = () =>
    onChange([...groups, { conditions: [{ ...EMPTY_CONDITION }] }])

  return (
    <div>
      {groups.length === 0 && (
        <div style={{ fontSize: 11, color: 'var(--text-muted)', padding: '2px 0 6px',
                      fontStyle: 'italic' }}>
          unconditional — fires immediately
        </div>
      )}

      {groups.map((group, gi) => (
        <React.Fragment key={gi}>
          {gi > 0 && (
            <div style={{ textAlign: 'center', padding: '3px 0', fontSize: 10,
                          color: 'var(--accent)', fontWeight: 700, letterSpacing: 1 }}>
              OR
            </div>
          )}

          <div style={{ border: '1px solid var(--border)', borderRadius: 4,
                        padding: '6px 8px', marginBottom: 2 }}>
            {group.conditions.map((cond, ci) => (
              <React.Fragment key={ci}>
                {ci > 0 && (
                  <div style={{ fontSize: 10, color: 'var(--text-muted)', fontWeight: 700,
                                padding: '2px 0', letterSpacing: 1 }}>
                    AND
                  </div>
                )}
                <ConditionRow
                  condition={cond}
                  toolkit={toolkit}
                  hwModuleNames={hwModuleNames}
                  onChange={updated => updateCondition(gi, ci, updated)}
                  onDelete={() => deleteCondition(gi, ci)}
                />
              </React.Fragment>
            ))}

            <button
              onClick={() => addAndCondition(gi)}
              style={{ marginTop: 4, fontSize: 11, background: 'none', border: 'none',
                       color: 'var(--accent)', cursor: 'pointer', padding: '2px 4px' }}
            >+ AND</button>
          </div>
        </React.Fragment>
      ))}

      <button
        onClick={addOrGroup}
        style={{ marginTop: 6, fontSize: 11, background: 'none',
                 border: '1px dashed var(--border)', color: 'var(--accent)',
                 cursor: 'pointer', borderRadius: 4, padding: '4px 10px', width: '100%' }}
      >+ OR group</button>
    </div>
  )
}
```

1. **Click a transition edge** → right panel shows `ConditionGroupsEditor` with one group card
   containing the existing condition row; `IfActionEditor` elsewhere still works unchanged.
2. **Click "+ AND"** → second row appears with `AND` label between rows; edge label updates to
   `a ∧ b` after debounce save.
3. **Click "+ OR group"** → second card appears with `OR` separator; label updates to `a ∧ b ∨ c`.
4. **Delete a row with ×** → row removed; deleting the last row in a group removes the card.
5. **Delete all groups** → "(unconditional — fires immediately)" hint visible; label shows
   `(unconditional)`.
6. **Reload** → compound expression restored from saved `condition_groups` JSON.
7. **IfActionEditor** — open a state's if-action condition → still shows single `ConditionBuilder`
   row; editing works normally.
