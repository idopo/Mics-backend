   the API, not a reason to import a private name.

   frames sent, `stats.dropped`, `stats.abandoned`, and connect/disconnect transitions. Wall-clock
   duration is allowed as a duration; it is never compared to anything on the Pi. Phase 28 owns
   timing (34-CONTEXT.md `<deferred>`).

   implementation anywhere in either autopilot tree — `cmd_id` and `"CMD"` appear nowhere outside
   `external_hardware_wire.py` itself. There is no Pi-initiated round trip to test against.
   SDK-08's evidence is synthetic-frame unit tests (plan 34-04) and that is a REAL, PERMANENT
   limitation of this phase, recorded as such. `/gsd:verify-work` must not be told SDK-08 was
   rig-proven.

4. **Nothing on the rig is changed, deployed, torn down or restarted by this plan** beyond the
   pilot restart the USER performs for the SDK-07 row. No new task definition, no new module, no
