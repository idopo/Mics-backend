outside `fda_json`.

to the Pi. A separate column is locked decision 1 in `29-CONTEXT.md`.

move, and the matching TypeScript types. Nothing consumes it yet — plan 29-06 does.

    - A ui_layout-only PUT succeeds even when the stored `fda_json` would fail validation —

      `toolkit_id` that does not resolve, or by monkeypatching `reject_if_hard_errors` to raise
      and asserting the layout PUT still returns 200. This is the CANVAS-10 guarantee at the
      backend layer: a node drag must never be rejected because of unrelated FDA state
    - A PUT carrying BOTH `fda_json` and `ui_layout` writes both and DOES rehash (the fast path
      must not swallow a real FDA edit)
    - `GET` on a definition that has never had a layout returns `ui_layout: None`
