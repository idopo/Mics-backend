<objective>
Take the "before" half of the acceptance measurement, on the pre-migration image, while it still
exists.

Purpose: **this is a one-way door.** The moment the spare card is reflashed to Bookworm (plan 09),
the pigpio baseline becomes unobtainable on that hardware. A phase whose acceptance gate is a
*paired* comparison, taken on the same board in the same session, has to take the baseline first.
Getting this wrong means either an unpaired comparison against numbers from a different machine, or
reflashing back and losing an afternoon.

Two secondary one-time measurements ride along because they need the same hardware in the same
state:
- **V2, counter wraparound.** pigpio's tick is 32-bit microseconds and wraps every
  `2**32 / 1e6 / 60` = **71.58 minutes** — about 20 times a day under continuous operation. One
  75-minute capture demonstrates the re-sync discontinuity with data. For lgpio no experiment is
  needed (64-bit nanoseconds wraps in ~584 years), but the harness asserts the field width so the
  claim is machine-checked rather than asserted in prose.
- **Instrument calibration.** A loopback capture cannot distinguish "the output edge was late" from
  "the input interrupt was serviced late". One external-observer cross-check settles whether the
  method agrees with reality; after that, the loopback is the routine instrument.

Output: committed baseline captures, a committed calibration verdict, and the phase evidence log.
</objective>
