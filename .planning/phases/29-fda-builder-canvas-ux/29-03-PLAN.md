```ts
export interface XY { x: number; y: number }

export interface LayoutInput {
  /** Every state name in the FDA — `Object.keys(fdaJson.states)`. */
  states: ReadonlyArray<string>
  /** `fdaJson.transitions`, structurally. Self-transitions are ignored for ranking. */
  transitions: ReadonlyArray<{ from: string; to: string }>
  /** `fdaJson.initial_state`. May be '' — a task definition can legitimately have none yet. */
  initialState: string
}

/** BFS-ranked layered arrangement. Every input state appears in the result. */
export function layeredLayout(input: LayoutInput): Record<string, XY>

/** A position colliding with nothing in `taken`. Never mutates or returns `taken`. */
export function placeNewState(taken: Readonly<Record<string, XY>>): XY

/**
 * The one function TaskEditor calls. Stored positions win verbatim; states absent from
 * `stored` are placed without moving anything stored. A null/empty `stored` means a full
 * `layeredLayout`.
 */
export function resolvePositions(
  input: LayoutInput,
  stored: Readonly<Record<string, XY>> | null | undefined,
): Record<string, XY>
```

    - Linear chain `IDLE→CUE→REWARD` with `initialState:'IDLE'` → three distinct x values, strictly
      increasing in BFS order; assert `x(IDLE) < x(CUE) < x(REWARD)`
    - Two states at the same depth (`IDLE→A`, `IDLE→B`) → same x, distinct y
    - Diamond (`IDLE→A`, `IDLE→B`, `A→END`, `B→END`) → `END` sits at depth 2, one column right
      of A and B, not duplicated
    - A cycle (`A→B`, `B→A`, initial `A`) does not hang and places both states
    - **Unreachable state is placed, never dropped**: states `[IDLE, ORPHAN]` with only `IDLE→IDLE`
      → `Object.keys(result).length === 2`, and `x(ORPHAN) > x(IDLE)` (trailing column)
    - Two unreachable states get the same trailing x and distinct y
    - No two states share a coordinate, for every case above (assert via a Set of `` `${x},${y}` ``
      with size equal to state count)
    - `states: []` → `{}`, no throw
    - Single state → one entry, no throw
    - `initialState: ''` (no initial state set) → every state still placed, no throw. Decide and
      document the rule: with no root, every state is unreachable, so they all land in the
      trailing column — assert exactly that, do not leave it implicit
    - `initialState` naming a state not in `states` → no throw, all states still placed
    - Self-transitions (`A→A`) do not affect ranking and do not create a phantom column
  </behavior>
  <action>
    Create `web_ui/react-src/src/components/fdaLayout.mts` with `layeredLayout` per the pinned
    signature.

    Algorithm:
    1. Build an adjacency map `from → to[]` from `transitions`, skipping `from === to`.
    2. BFS from `initialState` (if it is a known state), assigning `depth` on first visit. Guard
       against revisits so cycles terminate.
    3. Any state never visited gets `depth = maxVisitedDepth + 1` (the trailing column). With no
       valid `initialState`, `maxVisitedDepth` is -1 so everything lands in column 0.
    4. Group by depth; within each column, order by the original `states` array order (stable,
       so the arrangement is deterministic across reloads) and spread vertically, centring the
       column about y=0 so short columns sit beside tall ones without a ragged top.
    5. `x = depth * COLUMN_SPACING`, `y = (rowIndex - (columnSize - 1) / 2) * ROW_SPACING`.

    Constants at module top with a one-line comment each. Start from `COLUMN_SPACING = 320`,
    `ROW_SPACING = 180` (wider than today's 270/170 because bowed edges and their labels now
    need the corridor) and tune in plan 29-07 if the checkpoint says otherwise.

    Explicit return types on all exports. No `any`. No imports.
