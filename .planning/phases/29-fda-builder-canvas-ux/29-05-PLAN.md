<!-- @xyflow/react ^12.0.0, verified against node_modules on 2026-08-05 -->

`EdgeProps` gives a custom edge: `id, type, animated, data, style, selected, source, target,
selectable, deletable` + `EdgePosition` (`sourceX, sourceY, targetX, targetY, sourcePosition,
targetPosition`) + `EdgeLabelOptions` (`label, labelStyle, labelShowBg, labelBgStyle,
labelBgPadding, labelBgBorderRadius`) + `markerStart?: string, markerEnd?: string` (already-resolved
`url(#id)` strings).

`BaseEdgeProps` accepts: `path` (required), `labelX`, `labelY`, `label`, `labelStyle`,
`labelShowBg`, `labelBgStyle`, `labelBgPadding`, `labelBgBorderRadius`, `markerStart`, `markerEnd`,
`interactionWidth` (default 20 — this is what keeps the edge clickable), plus SVG path attributes.

**Arrowhead orientation is free.** `@xyflow/react`'s `Marker` renders `orient='auto-start-reverse'`
(`dist/esm/index.js:2349`), so SVG orients the arrowhead to the path's tangent at its endpoint
automatically. Setting `markerEnd: { type: MarkerType.ArrowClosed, ... }` on the Edge object and
forwarding the resolved `markerEnd` prop to `<BaseEdge>` satisfies CANVAS-03's "follow the curve's
tangent, not the straight-line angle" with no manual angle maths. Do NOT hand-roll a marker or
rotate an arrow polygon. `MarkerType` is exported from `@xyflow/react`.
