<objective>
Make the recorded path visible, let a researcher skip a device for one run, and stop marker-label
drift at authoring time.

Purpose: a path that lives only in the database is a path someone ends up asking a human to look up
— which is the manual step this phase exists to remove. And the per-run opt-out exists because rigs
get used for quick behavioural checks where ephys is irrelevant; without an escape hatch the
readiness gate turns each of those into a toolkit edit.

**Rendered by device, not by device type.** The component reads `artifacts[]` and renders one row per
`device_name`; a DeepLabCut row appears alongside an ephys row with no change here.
Output: one types addition, one api helper, two component changes.
</objective>
