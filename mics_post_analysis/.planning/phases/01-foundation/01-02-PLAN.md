# Phase 1, Plan 2: Notebook skeleton (docs + SESSIONS + resolve cell)

**Phase goal:** The single generic notebook exists with its documentation header, the editable `SESSIONS` block, and a working resolve cell — the shell every later section plugs into.

**Context:**
The notebook is the product surface. To keep it reviewable and reproducible we generate it from a Python script using `nbformat` (legacy notebooks were giant hand-edited JSON blobs — the thing we're replacing). This plan builds only the skeleton: header + config + resolve. Sections 1–4 are appended by later phases' plans.

**Depends on:** `mics.resolve.load_sessions`, `SessionConfig`, `ResolvedSession.summary()` from Plan 01-01.

---

## 1. `notebooks/build_notebook.py`

A script that assembles `mics_analysis.ipynb` via `nbformat.v4`. Keep cell content in clearly-labeled Python string blocks so future phases append cells by editing this script.

Cells, in order:

**md — Title + purpose**
> "# MICS Offline Analysis" — what it does (ES events always; ephys+spikes when present), who it's for.

**md — How to add a session**
- Edit the `SESSIONS` list below. Minimum fields: `key`, `es_subject`, `es_session`.
- Convention: ephys folder `<subject>s<n>_<date>_<time>` auto-resolved from the share; loose `spikes_<subject>s<n>.pkl` or inline `processed.xls` auto-found.
- `es_subject` is the descriptive ES string (e.g. `m74_cue_reward`), not the key.
- Optional overrides: `es_host`, `es_index`, `run_id`, channel/path overrides.

**md — How to run**
- Sections are independent: Section 1 (Events) needs only ES; Sections 2–4 add ephys/spikes/figure and self-skip when a session has no recording.

**code — imports + path bootstrap**
```python
import sys; sys.path.insert(0, "../src")
from mics.config import SessionConfig
from mics.resolve import load_sessions
```

**code — SESSIONS config block** (the one cell users edit)
```python
SESSIONS = [
    SessionConfig(key="m74s4", es_subject="m74_cue_reward", es_session=4),
    # SessionConfig(key="m74s1", es_subject="m74_cue_reward", es_session=1),
]
```

**code — resolve cell**
```python
sessions = load_sessions(SESSIONS)
for s in sessions:
    print(s.summary())
```

Script entry: `if __name__ == "__main__": nbformat.write(nb, "mics_analysis.ipynb")`.

## 2. Build + commit the notebook

- Run `python notebooks/build_notebook.py` to produce `notebooks/mics_analysis.ipynb`.
- Execute the notebook top-to-bottom (e.g. `jupyter nbconvert --to notebook --execute --inplace notebooks/mics_analysis.ipynb`) to confirm the resolve cell prints the `m74s4` summary line with `Record Node 110` + `pickle`.
- Commit both the build script and the generated `.ipynb` (notebook output stripped or minimal — only the resolve summary text).
