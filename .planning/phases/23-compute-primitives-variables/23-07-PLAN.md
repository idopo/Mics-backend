<objective>
Make preflight tell the truth about compute: stop it crying wolf on an intentionally empty
compute config, self-heal a missing one, and add the two new issue kinds this phase promised.
Then expose the variable-usage analysis the editor's read-only inspector needs.

Purpose: `preflight_validate` step 6 flags ANY config with no keys besides `class_name` as
`incomplete_config`. A compute module's config is *supposed* to be exactly
`{"class_name": "ComputeOps"}` — so every pilot running a compute-using toolkit would show a
spurious warning on the pre-run modal. The check was written assuming every module needs at
least one real parameter; compute modules are the first case that legitimately needs zero.
Output: preflight is trustworthy for compute, and CMP-15's backend half is wired in.
</objective>
