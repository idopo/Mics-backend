The Pi's frozen envelope (from `external_hardware_wire.py`'s module docstring — READ-ONLY):

```
SIG  {k, ts_src, seq, sig, v}          signal update, latest-value semantics
EVT  {k, ts_src, seq, evt, p}          event with payload
HB   {k, ts_src, seq}                  heartbeat
ACK  {k, ts_src, cmd_id, result}       command result (NO seq field)
CMD  {k, ts_pi, cmd_id, name, args}    Pi -> SDK only
```

The Pi's encoder, which the SDK must match byte-for-byte:

```python
# READ-ONLY reference: external_hardware_wire.py:63-69
def encode(kind, **fields):
    if kind not in WIRE_KINDS:
        raise ValueError("encode: unknown wire kind {!r}".format(kind))
    payload = {"k": kind}
    payload.update(fields)
    return msgpack.packb(payload, use_bin_type=True)
```

<decisions>
## Decisions locked by this plan — implement them, do not re-litigate

1. **Canonical golden-corpus reference = `~/mics_core/autopilot/autopilot/hardware/external_hardware_wire.py`.**
   Direct user direction, 2026-08-26: *"we are working on mics_core."* `~/pi-mirror/...` becomes
   the SECONDARY, skip-if-absent drift check. The two were verified byte-identical on 2026-08-26;
   this changes which path is named as the source of truth, not the corpus bytes. The decision and
   its date live in `sdk/tests/pi_reference.py`'s module docstring — one named place, not scattered
   string literals.

2. **`pyproject.toml` is a deliberate, narrow exception** to this repo's "services use
   requirements.txt" convention. `sdk/` is a redistributable package for machines outside this
   repo entirely. Say so in a comment at the top of `pyproject.toml` rather than silently
   contradicting the convention.

3. **`setuptools` + explicit `where = ["src"]`, not `hatchling`.** Hatchling's VCS-aware default
   file discovery is unverified for a subdirectory build inside this monorepo; the setuptools
   shape was empirically proven end-to-end on this host (34-RESEARCH.md, Packaging).

4. **Field kwarg order is load-bearing.** `payload.update(**fields)` preserves kwarg order and
   `msgpack.packb` preserves dict order, so byte parity constrains INSERTION ORDER, not just the
   key set. Call sites must pass `ts_src, seq, sig, v` / `ts_src, seq, evt, p` / `ts_src, seq` /
   `ts_src, cmd_id, result` in exactly that order.

5. **`ts_src` stays wall-clock.** The Pi ignores it for FDA purposes (`ts_pi_recv` is canonical).
   Do NOT "fix" it to a monotonic clock — that would make it look comparable across unsynced
   machines. **No latency is asserted anywhere in this phase** (that is Phase 28).

6. **`decode_envelope` never raises** — returns `None` on anything malformed. Counting, not
   raising, mirrors the Pi's EXTLINK-08 posture. Unlike the Pi's version it takes no `stats`
   argument; the SDK's callers own their own counters.
</decisions>
